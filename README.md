## File Format

Each translation is stored as a UTF-8 Markdown file in [`texts`](texts) and follows the same structure:

```markdown
# Localized title

**Language name**

Localized text
```

File names use BCP 47 language tags, including language codes and additional subtags where needed to identify language variants.

## Usage

The texts can be copied or loaded directly from the Markdown files for:

- Typeface specimens and font previews
- Glyph coverage and fallback testing
- Multilingual typesetting and line-breaking tests
- Localization and internationalization demonstrations
- Reading and language comparison samples

## Contributing

Contributions for corrections and additional languages are welcome. Keep translations faithful to the same concise version of the fable and preserve the existing file structure. Use the language's natural title, spelling, capitalization, punctuation, and writing conventions rather than mirroring English mechanically.
