# ᰕᰦᰛᰳ ᰛᰬᰰᰛ ᰇᰴ ᰔᰤᰶ

**ᰛᰩᰵᰛᰢᰵᰒᰧᰶ ᰉᰧᰵ**

ᰕᰦᰛᰳ ᰛᰬᰰᰛ ᰇᰴ ᰔᰤᰶ ᰀᰆᰩ ᰀᰣᰵ ᰕᰧᰵᰔᰧᰵ ᰘᰦᰰᰄ ᰀᰩᰵᰰ ᰉᰧᰵᰍᰧ ᰛᰤᰵᰰᰛᰣᰵ. ᰀᰣᰵ ᰀᰩᰰᰶᰛᰣ ᰀᰪᰵ ᰕᰝᰫ ᰋᰪᰵᰰ ᰚᰧᰵᰎᰧ ᰀᰩᰵ ᰕᰝᰧ ᰘᰤᰵᰰᰛᰣᰵ. ᰀᰧᰶᰰ ᰌᰩ ᰀᰆᰩ ᰀᰣᰵ ᰕᰩᰛᰶᰰ ᰄᰤᰶ ᰕᰝᰧᰵ ᰔᰧᰵᰰᰌᰤᰰ ᰕᰩᰵ ᰀᰪᰵ ᰀᰪᰵ ᰘᰦᰰᰄ ᰀᰩᰵ ᰉᰤᰵᰰᰛᰣᰵ ᰉᰧᰵᰍᰧ ᰛᰤᰵᰰᰛᰣᰵ. ᰕᰦᰛᰳ ᰛᰬᰰᰛ ᰍᰩ ᰊᰩᰵ ᰚᰤᰵᰰᰔᰤᰵᰰ ᰕᰩᰵᰰᰛᰣᰵ. ᰀᰧᰶᰰ ᰌᰩᰵ ᰁᰩᰵ ᰍᰩ ᰆᰧᰵᰰᰔᰤᰵ ᰀᰩᰵ, ᰀᰪᰵ ᰕᰩᰛᰶᰰ ᰄᰤᰶ ᰕᰝᰧᰵ ᰕᰩᰵ ᰄᰩᰵᰰᰔᰣᰵ ᰇᰧᰵᰰᰎᰤᰵᰰ ᰎᰩᰵᰰᰛᰣᰵ. ᰒᰩᰵᰰᰛᰧ ᰕᰦᰛᰳ ᰛᰬᰰᰛ ᰛᰣᰵᰰᰛᰣᰵ. ᰇᰴ ᰔᰤᰶ ᰍᰩ ᰕᰩᰛᰶᰰ ᰄᰤᰶ ᰕᰝᰧᰵ ᰀᰩᰵ ᰉᰩᰵᰰᰒᰦᰰ ᰂᰩᰵᰰᰛᰣᰵ, ᰀᰪᰵ ᰕᰩᰛᰶᰰ ᰄᰤᰶ ᰕᰝᰧᰵ ᰍᰩ ᰕᰩᰵ ᰔᰧᰵᰰᰌᰤᰰ ᰕᰩᰵ ᰀᰪᰵ ᰕᰩᰵᰰᰛᰣᰵ. ᰕᰦᰛᰳ ᰛᰬᰰᰛ ᰍᰩ ᰇᰴ ᰔᰤᰶ ᰀᰪᰵ ᰕᰧᰵᰔᰧᰵ ᰘᰦᰰᰄ ᰀᰩᰵ ᰍᰧᰵᰰᰛᰣᰵ.
